The Stormchaser Kubernetes runner is installed in {{ .Release.Namespace }}.
Workflow steps run as Jobs in the namespace {{ include "stormchaser-runner-k8s.stepNamespace" . }}.

1. Check that the runner has connected to NATS and registered with the engine:

  kubectl logs --namespace {{ .Release.Namespace }} -f deployment/{{ include "stormchaser-runner-k8s.fullname" . }}

2. The runner has no user interface. Port 8080 serves only health checks
   (/healthz and /readyz). To check readiness by hand:

  kubectl port-forward --namespace {{ .Release.Namespace }} deployment/{{ include "stormchaser-runner-k8s.fullname" . }} 8080:8080
  curl http://127.0.0.1:8080/readyz

3. Step logs are not shipped by the runner. A log collector on the nodes must send
   the step pods' logs to Loki for the API to show them; see docs/observability.md.
